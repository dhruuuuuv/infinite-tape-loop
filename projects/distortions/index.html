Distortions is a mental health web-app visualising some of the most common cognitive distortions, and how to help break their hold. It illustrates these by giving a description of the distortion, and then outlining a real world example of when this distortion may occur.

About Cognitive Distortions#

Cognitive distortions are systematic patterns of thinking that can lead to negative emotions and behaviors. These automatic thought patterns often occur without conscious awareness and can significantly impact mental well-being.

The App#

The web application provides an interactive way to learn about and recognize these patterns in everyday thinking. By presenting clear descriptions alongside real-world scenarios, it helps users develop awareness of their own thought processes and provides tools for challenging distorted thinking patterns.

Features#

  • Interactive exploration of common cognitive distortions
  • Real-world examples for each distortion type
  • Educational content to help break negative thought patterns
  • Clean, accessible interface for mental health awareness

Impact#

This project aims to make mental health resources more accessible by providing an easy-to-use educational tool that helps people recognize and understand cognitive distortions in their daily lives.
